Overview & Principles

Vouch collects video reviews and social proof for businesses. The UI is calm, flat, and frictionless — inspired by Cal.ai, Linear, and Tally. Geist as the sole typeface. The dashboard is a flat workspace (not a card grid): content lives in structured rows, sections, and inline lists within a single-plane layout.

Flat Workspace UI — Dashboard Layout

The dashboard is not a grid of cards. It's a flat, linear workspace: sidebar navigation + a content plane built from rows, horizontal rule-divided sections, and stat strips. Card elements can appear inside this plane (e.g. modals, inline review previews), but the overall layout is flat and table-like — closer to Linear, Notion, or Cal.ai than to a card-based product dashboard.

Flat Workspace Anatomy
Sidebar — Navigation + workspace switcher. Border-right only, bg-subtle tint. No shadow.
Top bar — Flat, border-bottom only. Title + tabs + search + actions. Height: 48px.
Stat strip — Horizontal ruled cells. Border separators only. No floating cards.
Section headers — Full-width row, border-top + border-bottom. Label + action.
Content rows — Border-bottom divided list. Hover tint. No individual card borders.
Card exceptions — Small card units (review embed, modal) are OK within the flat plane, sparingly.

Usage Guidelines

✓ Do
Use Geist at all times. Weight 400 / 500 / 600 only.
Keep the dashboard flat workspace — stat strips, ruled rows, no card grid.
Use Vermillion only for the record CTA and live-recording indicators.
Prefer border divisions over shadows to separate content areas.
Use radius-xl (10px) for the few card elements within the flat workspace.
Keep the recorder widget fully neutral — no strong brand colors for customer-facing screens.
Use letter-spacing -0.02 to -0.03 on all headings and stats.
✗ Don't
Don't build the main dashboard as a card grid — use flat rows and ruled sections instead.
Don't mix Geist with any other typeface — one font only.
Don't use Vermillion as background for sections, cards, or decoration.
Don't use shadows where border + background-subtle is sufficient.
Don't use semantic colors decoratively — green = success, red = error, always.
Don't put more than one Primary CTA per screen — maintain hierarchy.
Don't animate layout properties — only opacity, transform, color.
